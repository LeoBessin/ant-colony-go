## Supports de cours absents de ce depot

Les trois PDF du cours (`bareme-evaluation-performance-for-backend.pdf`,
`support-performance-for-backend-j1_am.pdf`, `support-performance-for-backend-j1_pm.pdf`)
sont les documents pedagogiques de l'intervenant et ne sont **pas** versionnes
ici : ce depot est public, et leur rediffusion releve de son droit d'auteur.

Ils sont references dans `CLAUDE.md` et dans le rapport. Pour travailler sur
le projet, les deposer dans ce dossier ; `.gitignore` les tient hors des
commits.
